In order to create the mask algorithm, we created the program \texttt{maskin\_dataset.py}, which is applied a mask to all data rainfall data and saves it in new \texttt{datasets.nc}.

The following algorithm was developed to create the land mask:

\begin{enumerate}[label=\arabic*.]
	\item A shapefile downloaded from \url{https://www.naturalearthdata.com} is provided as input.
	\item Latitude and longitude vectors are created to store coordinate information derived from the shapefile.
	\item The shapefile data is filtered to extract only the United States region and stored in the variable \texttt{usa}. A GeoDataFrame is then created from this.
	\item Using the latitude and longitude values, a grid is generated, and point geometries are created.
	\item A land mask is generated from these points based on whether they fall inside or outside the USA geometry.
	\begin{enumerate}[label=\alph*.]
		\item To mask areas outside the United States, the following expression is used:
		\texttt{land\_mask\_flat = \~ gdf\_points.within(usa.unary\_union)},
		which returns the points that do not intersect with the USA polygon.
	\end{enumerate}
